# Knowledge-to-Video Factory — Graphic Edition

## Intent

A brand-new 60-second graphic-first explainer for a hackathon audience. The
video makes the Knowledge-to-Video Factory feel like a living system: source
material enters, specialized agents shape understanding, a learning plan
forms, and the result becomes a visual lesson. The visuals carry the story;
copy stays short and supportive.

## Capability scan

- Brand package: none applied.
- User media: same six approved narration clips copied into this project under `assets/audio/`.
- Graphics: bespoke SVG and CSS primitives authored in a project-local component; no contact-sheet icons.
- Azure: unavailable in the current account, so no paid generation is used.
- Music: none, per the existing direction.

## Treatment

A fresh graphic-first treatment, separate from the earlier drafts. Six scenes
use different visual grammars: a signal field, an input funnel, an agent
orbit, a timeline, a quality waveform, and a final knowledge-to-learning
transformation. The original video is a quality reference only; it is not
copied or overwritten.

## Constraints

- 60 seconds total, 1920x1080, 30fps
- Same VO reused from the prior approved script
- No Copilot end card
- No Fluent contact-sheet PNGs
- Minimal on-screen text; visual motion and diagrams carry the explanation
- No generated or paid media
