### AnimatedCaption

Word-highlight or sentence-level caption overlay.

For narration subtitles generated by the SCF compiler, prefer active-line
captions: `panel: false`, `maxWordsPerLine: 5`, `backgroundColor: "transparent"`,
`timingOffsetSec: 0.07`, and a per-line `lineBackgroundColor` plus per-word
`highlightBackgroundColor`.
Only one short transcript line should be visible at a time; boxed caption
panels are opt-in only. Use a positive `timingOffsetSec` when transcript word
timestamps feel slightly ahead of the spoken narration.

| Prop | Type | Required | Default | Description |
|------|------|:--------:|---------|-------------|
| `text` | string | ✅ | — | Caption text content |
| `position` | `"top"` \| `"bottom"` | | `"bottom"` | Screen position |
| `fontSize` | number | | — | Font size in pixels |

```jsonc
{
  "component": "AnimatedCaption",
  "props": { "text": "AI-Powered Insights", "position": "bottom", "fontSize": 28 }
}
```
