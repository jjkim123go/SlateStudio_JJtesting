Script

script.md · shimmer · 58s narration
S1 — HOOK 0:00 – 0:06
Meet GitHub Copilot — your AI pair programmer, right inside VS Code.
S2 — COMPLETIONS 0:06 – 0:19
Just start typing. Copilot reads your intent and suggests whole lines — even entire functions — as ghost text. Like what you see? Press Tab, and it's yours.
S3 — CHAT 0:19 – 0:30
Got a question? Open Chat and just ask, in plain English. Explain this code. How do I fix this? Copilot answers using the context of your own files.
S4 — EDITS 0:30 – 0:41
Need a change? Select your code, press Control I, and describe it — add error handling. Copilot rewrites it in place and shows a clean diff to accept.
S5 — AGENT 0:41 – 0:51
For bigger jobs, switch to Agent mode. Describe a goal, and Copilot edits across multiple files and runs commands for you — while you stay in control.
S6 — CTA 0:57 – 1:03
That's Copilot in VS Code. Turn it on, and start building faster today.
