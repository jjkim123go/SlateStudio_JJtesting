# BookingsScene Component

> Layer 2 component skill. Load when a scene needs a Microsoft Bookings style
> scheduling page, appointment service list, or booking workflow.

## When to use

**Trigger vocabulary:** `Bookings, appointment scheduling, booking page,
services page, booking calendar, self-serve scheduling, appointment modal`.

Choose `BookingsScene` when the viewer should understand how time is offered or
reserved. Prefer `OutlookScene` for calendar mail workflows and `OneDriveScene`
for document sharing.

## Variants

- `home`
- public-page / create-modal style fixtures
