# WhiteboardScene Component

> Layer 2 component skill. Load when a scene needs Microsoft Whiteboard style
> ideation, sticky-note clustering, or diagramming.

## When to use

**Trigger vocabulary:** `whiteboard, brainstorm, sticky notes, retro,
diagram board, template retro, collaborative sketch, ideation canvas`.

Choose `WhiteboardScene` for spatial ideation. Prefer `LoopScene` for document-
like collaboration and `ArchitectureDiagram` for polished system diagrams.

## Variants

- `brainstorm`
- `diagramMode`
- `templateRetro`
