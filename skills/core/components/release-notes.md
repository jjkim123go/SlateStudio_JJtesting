# ReleaseNotes Component

> Layer 2 component skill. Load when a scene needs a polished “what shipped”
> summary rather than a roadmap or a generic bullet slide.

## When to use

**Trigger vocabulary:** `release notes, changelog, what's new, shipped features,
GA update, hotfix, release summary, rollout notes`.

Choose `ReleaseNotes` for grouped product changes and highlights. Prefer
`Roadmap` for future milestones and `StepByStep` for tutorials.

## Authoring cues

- Group items by category or theme if the release spans multiple areas.
- Use concise titles and one-line bodies; this component is for scanability.
- Mention hotfixes separately from flagship items when both exist.
