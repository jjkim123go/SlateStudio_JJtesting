# OKRStatus Component

> Layer 2 component skill. Load when a scene needs an objective-and-key-result
> rollup with confidence or initiative status.

## When to use

**Trigger vocabulary:** `OKR, objective, key result, goal progress, quarterly
goal, confidence, initiative status, scorecard`.

Choose `OKRStatus` when the structure is goal-first. Prefer `MetricsCard` for a
single KPI and `Roadmap` for time-based sequencing.

## Authoring cues

- Model top-level goals as objectives and nested outcome lines as key results.
- Use confidence / health labels only when the narration explicitly calls them
  out.
- Keep each scene to a small set of objectives so the viewer can scan quickly.
