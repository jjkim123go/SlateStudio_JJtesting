# LoopScene Component

> Layer 2 component skill. Load when a scene should look like Microsoft Loop
> content being collaboratively edited in real time.

## When to use

**Trigger vocabulary:** `Loop, meeting notes, collaborative notes, task list,
kanban board, collaborative table, shared agenda, coauthoring workspace`.

Choose `LoopScene` when the artifact is a living collaborative canvas. Prefer
`WhiteboardScene` for freeform ideation and `ListsScene` for structured record
tracking.

## Variants

- `meetingNotes`
- `taskList`
- `kanbanBoard`
- `tableDatabase`
