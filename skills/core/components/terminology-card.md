# TerminologyCard Component

> Layer 2 component skill. Load when a scene introduces a term, definition,
> analogy, or “do not confuse with” concept.

## When to use

**Trigger vocabulary:** `term, definition, glossary, concept card, analogy,
do not confuse with, vocabulary, what does X mean`.

Choose `TerminologyCard` for concept teaching. Prefer `Quiz` for assessment and
`StepByStep` for process instruction.

## Authoring cues

- Lead with the term and its plain-English definition.
- Use the analogy or example fields for memory anchors, not for new content.
- Keep “do not confuse with” entries short and contrastive.
