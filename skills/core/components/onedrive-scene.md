# OneDriveScene Component

> Layer 2 component skill. Load when a scene needs a OneDrive-style file
> browser, share flow, or file-action moment.

## When to use

**Trigger vocabulary:** `OneDrive, my files, shared files, recent files, file
browser, share dialog, context menu, document handoff`.

Choose `OneDriveScene` when the story is about documents and sharing actions.
Prefer `ListsScene` for records and `BookingsScene` for scheduling flows.

## Variants

- `myfiles`
- share-dialog / context-menu style fixtures
