# PlannerScene Component

> Layer 2 component skill. Load when a scene should look like Microsoft Planner
> with task buckets, charts, or task-detail workflow.

## When to use

**Trigger vocabulary:** `Planner, task board, bucket board, plan charts, task
detail pane, team planning, plan schedule`.

Choose `PlannerScene` when the story is about team task management. Prefer
`LoopScene` for collaborative notes and `ProgressBar` for abstract progress.

## Variants

- `board`
- `charts`
- task-open / task-detail style fixtures
