# AskTheAudience Component

> Layer 2 component skill. Load when a scene needs to visualize live audience
> poll results or session participation.

## When to use

**Trigger vocabulary:** `live poll, audience question, response bars, vote
results, audience sentiment, session interaction, poll outcome`.

Choose `AskTheAudience` for results-first poll scenes. Prefer `Quiz` when the
viewer is meant to answer first and `DataChart` for generic business charts.

## Authoring cues

- Keep answer options short enough to fit on bars cleanly.
- Include response count when the narration references audience size.
- Use it as an event beat, not as a dense analytical chart.
