# FormsScene Component

> Layer 2 component skill. Load when a scene should look like Microsoft Forms
> creating, previewing, or reviewing a form or quiz.

## When to use

**Trigger vocabulary:** `Forms, survey, quiz builder, form builder, response
preview, forms gallery, questionnaire workflow`.

Choose `FormsScene` when the story is about authoring or previewing forms.
Prefer `Quiz` for a single assessment card and `BookingsScene` for scheduling.

## Variants

- `home`
- `builder`
- `gallery`
- `preview`
