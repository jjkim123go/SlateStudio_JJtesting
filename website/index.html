The Process

From Prompt to MP4

An agentic, stage-gated production loop with creative direction, concrete preflight, and human approval before expensive work.

01 USER APPROVAL

Ingest

Analyze inputs — prompts, decks, docs, media files. Extract structure, identify content, build the creative brief.

PPTX · DOCX · XLSX · PDF · Media
02 AUTO

Research

Gather context, verify facts, analyze source material. Build the knowledge base that drives the script.

Web fetch · Document analysis
03 USER APPROVAL

Script

Write narration with timing, pacing, and tone. Scene-by-scene structure with duration targets and voice direction.

Narration · Timing · Voice
04 USER APPROVAL

Scene Plan

Map visuals to script. Choose components, decide image vs video vs structured visuals for each scene.

Layout · Components · Routing
05 AUTO

Assets

Generate images (gpt-image-2), narration (gpt-4o-mini-tts), AI video clips (Sora-2), and structured visuals — all cost-tracked.

~$0.04/img · ~$0.20/s video
06 SELF-REVIEW

Compose

Generate SCF JSON composition. Validate against schema. Compile to HyperFrames HTML and render to MP4.

SCF → HTML → Chrome → MP4
07 USER APPROVAL

Review

Reviewer sub-agent scores 8 dimensions and blocks missing captions, long static holds, unsupported visuals, and timing failures.

8 dimensions · blocker gates
08 USER CHOICE

Publish

Deliver the final MP4 with full audit trail. Choose delivery profile: internal, external, executive, or regulated.

MP4 · Audit · Cost log
Foundation

The Twelve Principles

Operating contract for every interaction. Not guidelines — rules.

P1

Agent-as-Director

The AI is the creative director. Shot composition, pacing, narrative flow — not just tool execution.

P2

Capability Manifest

Always check the tool registry before claiming something is impossible. Never guess — verify.

P3

Deterministic Workflow

The production loop is deterministic. The agent's creative direction lives in the script, scene plan, assets, and review decisions.

P4

SCF-First Composition

Generate SCF JSON, compile to HTML via HyperFrames, render to MP4. Declarative over imperative.

P5

Deep Artifact Understanding

Every input file is analyzed thoroughly — dimensions, colors, text, duration, codecs — before any decisions.

P6

Review via Sub-Agent

Independent reviewer sub-agent scores 8 dimensions and blocks narration/visual mismatch, missing captions, and static slideshow drift.

P7

Human-in-the-Loop

Checkpoints at ingest, script, scene plan, and compose. Nothing ships without explicit human approval.

P8

Tool Creation Escape

If a needed capability doesn't exist, create a new tool following the BaseTool contract. Never give up.

P9

Single-Responsibility

Each tool does one thing well. Compose small tools into workflows — never build monoliths.

P10

Externalized State

All state lives on the filesystem. Cost logs, production traces, assets — never only in memory.

P11

Progressive Disclosure

Start with defaults: 1080p, 30fps, no brand package. Add complexity only when the user asks for it.

P12

Fail Forward

Never silently drop content. Report failures, explain alternatives, and try a different path. Full transparency.
