## Video direction

Palette: cool-white Fluent canvas; Microsoft blue carries continuity, with cyan,
green, yellow, and red used only for semantic state changes. Display type is
heavy Montserrat; labels use JetBrains Mono. Fluent PNG icons are the subjects.

Motion grammar: smooth long-tail settles, precise path travel, and sequential
reveals paced to each spoken cue. The narrated sequence grows from a single
document into a connected production system. Frame 6 is the deliberate held
read before the silent end card. Never front-load then freeze, and never let
elements float independently like a screensaver.

Rhythm: curiosity → orientation → focused work → momentum → confidence → held
resolution → silent brand close. No music; narration and visual state changes
carry the timing.
