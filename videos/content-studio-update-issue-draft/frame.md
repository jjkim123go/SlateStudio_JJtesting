# Reference-Matched Content Studio Quick Start

- Intro: dark green field, mustard rounded label, heavy white centered headline,
  and a large UI crop rising from the lower edge.
- Product demo: bright white Content Studio interface using Inter as a close,
  render-safe match to the sample's Microsoft sans typography.
- Pointer: oversized white arrow or hand with a heavy black outline.
- Camera: slow 1.0 to 1.20 pushes toward the active control, followed by a calm
  return to the full workspace. No whip pans or decorative transitions.
- Pacing: actions unfold over 10 to 20 seconds, with visible holds after each
  click so viewers can read the changed state.
- Close: centered Microsoft four-color mark and gray wordmark on white.
